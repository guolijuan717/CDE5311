# Daily Focus

A locally runnable React + TypeScript + Vite prototype recreated from the Figma Daily Focus State A / State B frames.

## Run on your Mac

1. Install Node.js (version 20 or later).
2. Open Terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite (usually http://localhost:5173).

Click any task to toggle completion; the progress updates automatically. Click **Reset demo** to restore the original 2-of-4 state.

No GitHub repository or remote deployment is required.
